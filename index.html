New to terminals? How to use this one
  • Click any button or underlined command and it types itself, so you can see what the command looks like.
  • Type a command such as help and press Enter to run it.
  • Press Tab to auto-complete. Type pro then Tab and you get projects.
  • Press ↑ / ↓ to go through commands you already ran.
  • Type clear (or press Ctrl+L) to wipe the screen.
  • You can also just ask something in plain English, like "what do you do?"
